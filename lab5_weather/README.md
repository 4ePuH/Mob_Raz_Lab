# Лабораторная работа №5 - Прогноз погоды

Погода по названию города на Flutter.

API - [Open-Meteo](https://open-meteo.com/), бесплатный и без ключа. Запросов два:
1. геокодер ищет город по названию и даёт координаты
   (`https://geocoding-api.open-meteo.com/v1/search?name=Москва&language=ru`)
2. по координатам берётся текущая погода и прогноз на 7 дней
   (`https://api.open-meteo.com/v1/forecast?...`)

Погода в ответе приходит кодом WMO (0 - ясно, 71 - снег и т.д.), текст и иконку
по коду подбирает `models/weather_code.dart`.

## Что умеет

- поиск города (Enter или кнопка с лупой)
- текущая температура, "ощущается как", описание и значок погоды
- влажность, скорость ветра, давление в мм рт. ст.
- прогноз на 7 дней: значок, описание, максимум и минимум
- состояния: загрузка, ошибка (с кнопкой "Повторить"), город не найден, пустой запрос
- ошибки: нет интернета, сервер не отвечает, 400, 404, 429, 5xx, кривой ответ
- потянуть список вниз - обновить
- при запуске сразу открывается последний город

Доп. задание: кэширование. После каждой удачной загрузки ответ сервера сохраняется
в shared_preferences. Если интернета нет, а этот город уже загружали, показываются
сохранённые данные с пометкой "Нет связи с сервером" и временем загрузки.
Если сервер доступен, но вернул ошибку (например 500), кэш не подставляется, показывается ошибка.

## Структура

```
lib/
  main.dart
  models/city.dart              - город из геокодера
  models/weather.dart           - текущая погода и прогноз по дням
  models/weather_code.dart      - код WMO -> текст и иконка
  data/api_config.dart          - адреса API
  data/weather_api_client.dart  - http-запросы и коды ответа
  data/weather_cache.dart       - кэш
  data/weather_repository.dart  - город -> прогноз, при отсутствии сети кэш
  state/weather_state.dart      - состояние экрана (ChangeNotifier)
  screens/weather_screen.dart   - экран
  widgets/                      - карточка текущей погоды и список прогноза
```

WeatherScreen -> WeatherState -> WeatherRepository -> WeatherApiClient.

## Запуск

```
flutter pub get
flutter run
```
