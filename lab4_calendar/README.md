# Лабораторная работа №4 - Календарь

Календарь с событиями на Flutter.

Сетка месяца сделана пакетом [table_calendar](https://pub.dev/packages/table_calendar),
названия месяцев и дней недели на русском через пакет intl.

## Что умеет

- показывает месяц, неделя начинается с понедельника, сверху месяц и год
- стрелками или свайпом можно перейти на предыдущий / следующий месяц, кнопка "Сегодня" возвращает к текущей дате
- выбранный день выделен, под календарём список его событий
- события сортируются по времени начала, в один день можно добавить сколько угодно
- создание и редактирование события на отдельном экране: название, дата, время начала, время окончания (можно выключить), категория, описание
- удаление с подтверждением
- событие без названия не сохранится; окончание должно быть позже начала и в тот же день

Доп. задание: цвета категорий. У события есть категория (Работа, Учёба, Личное, Другое),
у каждой свой цвет. В сетке под числом рисуются точки цвета категорий, в списке слева цветная полоска.

События хранятся в памяти (EventRepository), после перезапуска они пропадают.

## Структура

```
lib/
  main.dart                      - запуск, русская локаль
  models/event.dart              - модель события, категории, функции для дат
  data/event_repository.dart     - список событий в памяти
  state/calendar_state.dart      - выбранный день, текущий месяц, CRUD (ChangeNotifier)
  screens/calendar_screen.dart   - календарь и список событий дня
  screens/event_edit_screen.dart - форма события
  utils/format.dart              - форматирование дат и времени
```

CalendarScreen -> CalendarState -> EventRepository.

## Про даты

table_calendar передаёт дни в UTC, а события создаются в местном времени.
Если сравнивать такие даты через `==`, они не совпадут, поэтому дни сравниваются
по году, месяцу и числу (функция `isSameDate`).
