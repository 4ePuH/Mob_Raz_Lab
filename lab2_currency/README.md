# Лабораторная работа №2 - Конвертер валют

Конвертер валют на Flutter для дисциплины "Разработка мобильных приложений".

Курсы берутся из API ЦБ РФ: https://www.cbr-xml-daily.ru/daily_json.js (ключ не нужен).
ЦБ даёт курсы всех валют к рублю, поэтому, например, EUR -> USD считается через рубль.

## Что умеет

- ввод суммы (можно через точку или запятую)
- выбор исходной и целевой валюты, поиск по коду или названию
- кнопка смены валют местами, результат сразу пересчитывается
- показывает курс 1 единицы и дату, на которую ЦБ установил курс
- пока курсы грузятся - индикатор загрузки
- нет интернета или сервер вернул ошибку - сообщение и кнопка "Повторить"
- пустая, отрицательная или кривая сумма - подсказка под полем ввода

Доп. задание: избранные валюты. В списке валют можно отметить валюту звёздочкой,
избранные показываются сверху. Список сохраняется (shared_preferences) и не пропадает после перезапуска.

## Структура

```
lib/
  main.dart                     - запуск, сборка зависимостей
  models/currency.dart          - модель валюты и курсов, перевод суммы
  data/cbr_api_client.dart      - GET-запрос к API, ошибки сети
  data/currency_repository.dart - превращает JSON в модели
  data/favorites_storage.dart   - сохранение избранного
  state/converter_state.dart    - состояние экрана (ChangeNotifier)
  screens/converter_screen.dart - экран конвертера
  widgets/                      - кнопка валюты и список выбора
```

Цепочка как в задании: UI -> ConverterState -> CurrencyRepository -> ApiClient.

## Запуск

```
flutter pub get
flutter run
```

В браузере: `flutter run -d chrome`.

## Тесты

```
flutter test
```

Тесты не ходят в интернет, вместо сервера подставляется MockClient с заранее сохранённым ответом.
