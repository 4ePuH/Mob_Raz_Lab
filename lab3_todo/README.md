# Лабораторная работа №3 - Список задач

Приложение для ведения списка задач на Flutter.

## Что умеет

- добавить задачу (кнопка "Задача" внизу)
- изменить задачу - нажать на неё в списке, откроется тот же экран формы
- удалить - иконка корзины или свайп влево, удаление можно отменить в течение пары секунд
- отметить выполненной галочкой, выполненная задача зачёркнута
- фильтры: все / активные / выполненные, рядом число задач
- поиск по части названия, регистр не важен
- у каждой задачи видна дата и время создания
- задачу с пустым названием сохранить нельзя, форма покажет ошибку

Создание и редактирование - отдельный экран (Navigator.push), данные назад
возвращаются через Navigator.pop. Проверка названия сделана через Form и validator.

Доп. задание: локальное сохранение. Задачи сохраняются в shared_preferences
(в виде JSON) после каждого изменения и загружаются при запуске.

## Структура

```
lib/
  main.dart
  models/task.dart              - модель задачи, toJson/fromJson
  data/todo_repository.dart     - загрузка и сохранение задач
  state/todo_state.dart         - список, фильтр, поиск, CRUD (ChangeNotifier)
  screens/todo_screen.dart      - главный экран со списком
  screens/task_edit_screen.dart - форма создания/редактирования
  widgets/task_tile.dart        - одна строка списка
```

TodoScreen -> TodoState -> TodoRepository.

## Запуск

```
flutter pub get
flutter run
```

Тесты: `flutter test`
